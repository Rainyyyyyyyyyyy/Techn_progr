# Тест-кейсы

## Некорректные входные данные [P0]

- **0.1** Инициализация с пустым полем для пути к хост-файлу
- **0.2** Инициализация с помощью пути до папки, вместо хост-файла
- **0.3** Инициализация с помощью пути к хост-файлу формата отличного от `.txt`

---


## Тестирование хост-файла [P1]

- **1.** Хост-файл не существует
- **2.** Хост-файл существует, но скрыт
- **3.** Хост-файл существует, но имеет системные атрибуты

---


## Тестирование инициализации по содержимому хост-файла [P2]

- **1.** Хост-файл пуст
- **2.** Хост-файл содержит путь к несуществующему файлу
- **3.** Хост-файл содержит путь к существующему файлу - скрытому
- **4.** Хост-файл содержит путь к существующему файлу - с системными атрибутами
- **5.** Хост-файл содержит путь к папке
- **6.** Хост-файл содержит пустую(-ые) строку(-и)
- **7.** Хост-файл содержит путь к самому себе
- **8.** Хост-файл содержит повторяющуюся(-иеся) строку(-и)

---


## Тестирование по событиям для файла(-ов) *под наблюдением* [P3]
Предусловие к тест-кейсам ниже: файл находится под наблюдением (путь к файлу указан в хост-файле) 
- **1.** файл продолжает существовать
- **2.** файл только что был удалён
- **3.** файл продолжает быть удалённым
- **4.** файл только что был создан
- **5.** файл только что был изменён
- **6.** файл только что переместили
- **7.** файл только что переименовали
- **8.** из хост-файла удалили путь (вместе с дубликатами) к этому файлу

---


## Тестирование событий для файла(-ов) *не под наблюдением* [P4]
Предусловие к тест-кейсам ниже: файл находится **не** под наблюдением (путь к файлу **не** указан в хост-файле)
- **1.** в хост-файл добавили путь к этому файлу
- **2.** в хост файл добавили путь к этому файлу с дубликатами
- **3.** файл продолжает существовать
- **4.** файл только что был удалён
- **5.** файл продолжает быть удалённым
- **6.** файл только что был создан
- **7.** файл только что был изменён
- **8.** файл только что переместили
- **9.** файл только что переименовали
