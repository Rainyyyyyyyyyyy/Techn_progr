=== НЕКОРРЕКТНЫЕ ВХОДНЫЕ ДАННЫЕ [P0] ===
0.1 Инициализация с пустым полем для пути к хост-файлу
0.2 Инициализация с помощью пути до папки, вместо хост-файла
0.3 Инициализация с помощью пути к хост-файлу формата отличного от .txt


=== ТЕСТИРОВАНИЕ ХОСТ-ФАЙЛА [P1] ===
1. Хост-файл не существует 
2. Хост-файл существует, но скрыт
3. Хост-файл существует, но имеет системные атрибуты 


=== ТЕСТИРОВАНИЕ Init() по СОДЕРЖИМОМУ ХОСТ-ФАЙЛА [P2] ===
1. Хост-файл пуст
2. Хост-файл содержит путь к несуществующему файлу
3. Хост-файл содержит путь к существующему файлу - скрытому
4. Хост-файл содержит путь к существующему файлу - с системными атрибутами
5. Хост-файл содержит путь к папке
6. Хост-файл содержит пустую(-ые) строку(-и)
7. Хост-файл содержит путь к самому себе
8. Хост-файл содержит повторяющуюся(-иеся) строку(-и)


=== ТЕСТИРОВАНИЕ CheckStateOfFiles() по СОБЫТИЯМ для файла(-ов) под наблюдением [P3] ===
1. файл под наблюдением - файл продолжает существовать
2. файл под наблюдением - файл только что был удалён
3. файл под наблюдением - файл продолжает быть удалённым
4. файл под наблюдением - файл только что был создан
5. файл под наблюдением - файл только что был изменён
6. файл под наблюдением - файл только что переместили
7. файл под наблюдением - файл только что переименовали 
8. файл под наблюдением - из хост-файла удалили путь (вместе с дубликатами) к этому файлу


=== ТЕСТИРОВАНИЕ СОБЫТИЙ для файла(-ов) не под наблюдением [P4] ===
1. файл не под наблюдением - в хост-файл добавили путь к этому файлу
2. файл не под наблюдением - в хост файл добавили путь к этому файлу с дубликатами
3. файл не под наблюдением - файл продолжает существовать
4. файл не под наблюдением - файл только что был удалён
5. файл не под наблюдением - файл продолжает быть удалённым
6. файл не под наблюдением - файл только что был создан
7. файл не под наблюдением - файл только что был изменён
8. файл не под наблюдением - файл только что переместили
9. файл не под наблюдением - файл только что переименовали
